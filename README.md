# Anjana Creators Hub

Premium digital e-learning tutorials platform.
This custom web application provides high-quality video tutorials, comprehensive notes, interactive quizzes, and premium content for Facebook monetization and digital presence. 

**Note**: This project was custom-built for a client. 

## Features
- Secure Authentication
- Razorpay Payment Integration for Premium Subscriptions
- Multi-language Support (English / Malayalam)
- Custom Video Player & Course Rooms
- Interactive Quizzes & Automated Certificates
- Dynamic Admin Dashboard
